# Общение через Gemini

Функция выключена по умолчанию. Создайте ключ в https://aistudio.google.com/apikey
и добавьте его **только в `.env` сервера**, не в Git, Telegram или приложение.

```env
AI_CHAT_ENABLED=true
GEMINI_API_KEY=ваш_ключ
GEMINI_MODEL=gemini-3.5-flash-lite
AI_CHAT_IDS=-1001234567890,313842282
AI_CHAT_DAILY_LIMIT=200
```

В `AI_CHAT_IDS` укажите реальные ID разрешённых групп/личных чатов.
Пустой список не разрешает ни один чат. После изменения `.env`:

```sh
sudo docker compose up -d --no-deps --force-recreate bot
```

В разрешённом чате: `/ai вопрос`, упоминание `@имя_бота` или ответ
на сообщение бота. `/ai_clear` очищает свой диалог в текущей теме.
Команды и макросы сохраняют приоритет над ИИ. В личном чате используйте `/ai`.

Google получает только тексты обращений к ИИ и до шести последних пар
вопрос/ответ. Обычная переписка, числовые ID пользователей, база, ключи,
фото и файлы не передаются. Текст самого обращения может содержать
персональные данные: предупредите участников перед включением.
На бесплатном тарифе Google может использовать данные для улучшения
сервисов: https://ai.google.dev/gemini-api/docs/pricing

Память разделена по чату, теме и отправителю, хранится в RAM и забывается
после 30 минут бездействия либо перезапуска. ИИ не выполняет команды,
не получает инструментов и не управляет модерацией.

Ограничения: 2000 символов на вопрос, до 3500 символов на ответ,
пауза 10 секунд между вопросами, максимум три одновременных запроса.
Дневной счётчик (UTC) относится к одному процессу и сбрасывается при
перезапуске; это **не жёсткий лимит денег**. Настройте квоты/оплату в
Google отдельно. При ошибке API платные запросы автоматически не повторяются.
Модель можно сменить через `GEMINI_MODEL` согласно доступности в проекте.
