# Источники воздушных тревог

Управление перенесено в Mini App: «Админ» → «Модерация» → выберите группу → «Тревога». Там доступны автопроверка, источник, город NEPTUN, ограничения, ручной режим и тексты. Настройки может менять только администратор выбранной группы; назначенный модератор видит состояние без права записи.

Источник и город выбираются независимо для каждой группы. По умолчанию источник — `alerts_in_ua`, а город NEPTUN — Кривий Ріг; NEPTUN не требует токена. Возврат к Alerts.in.ua требует настроенного `ALERTS_API_TOKEN`. Выбор города применяется только к NEPTUN. Для Alerts.in.ua сохраняется существующая география: Криворізький район Дніпропетровської області.

Поддерживается 41 город из официальной карты сайта NEPTUN на 13 сентября 2026 года. Угроза относится к городу при совпадении населённого пункта, его района или областной записи `areaOnly`. Advisory и завершённые записи не включают оповещение.

## Миграция

При `Database.init()` автоматически и идемпотентно добавляется колонка:

```sql
ALTER TABLE alarm_api_settings
ADD COLUMN alert_source TEXT NOT NULL DEFAULT 'alerts_in_ua';

ALTER TABLE alarm_api_settings
ADD COLUMN alert_location TEXT NOT NULL DEFAULT 'kryvyi-rih';

ALTER TABLE alarm_api_settings
ADD COLUMN disable_requested INTEGER NOT NULL DEFAULT 0;
```

Существующие записи остаются на прежнем источнике и получают Кривий Ріг как город NEPTUN по умолчанию. Переключение источника или города сохраняет enabled, состояния, ID сообщений и ограничения: следующий успешный снимок согласует их с выбранной территорией. Активная тревога обновляет закреплённое сообщение; отбой снимает ограничения существующим механизмом. Ошибка запроса/структуры не означает отбой. Рабочая БД при разработке не изменялась; миграция выполнится при запуске обновлённого приложения. Перед обновлением используйте обычную резервную копию БД.

## Контракт провайдера

`app/alert_providers.py`: `AlertProvider.fetch()` получает общий снимок, а `state_for()` строит состояние выбранной территории. `AlertsInUaProvider` сохраняет существующие условные HTTP-запросы и диагностику. `NeptunProvider` принимает валидный список `threats`, сохраняет тип, уровень, описание и территорию угрозы. Пустой валидный список означает отсутствие активной угрозы; повреждённый ответ не применяется как отбой.

Реестр провайдеров находится в `alerts_monitor_loop`, подписи — в `SOURCE_LABELS`, города — в `NEPTUN_LOCATIONS`. Для третьего источника нужны адаптер, регистрация и тесты его формата; меню строится из списка источников. Каждый источник опрашивается один раз за цикл для всех подписанных групп, после чего состояния разных городов вычисляются локально. Запросы независимы, кеш разделён по источнику и городу. Автоматического переключения при недоступности нет.

## Проверенный протокол NEPTUN (13 сентября 2026)

Документация: https://neptun.in.ua/developers
Условия: https://neptun.in.ua/api-terms

REST: GET https://neptun.in.ua/api/v1/threats, без ключа. Используются официальные поля `type`, `region`, `district`, `locality`, `status`, `advisory`, `areaOnly`, `confirmedAt`, `updatedAt`, `explanationShort` и `title`. Типы `uav`, `fpv`, `recon`, `missile`, `ballistic`, `kab`, `mig31k` и `unknown` переводятся в существующие категории сообщений бота.

WebSocket: wss://neptun.in.ua/api/v1/stream. Конверт `{type, ts, data}`. Событие `alerts` содержит `{raions, oblasts}`; `upsert`/`remove` относятся к трекам угроз, а не к объявлению/отбою официальной тревоги. Документация также описывает snapshot и heartbeat. При реализации WebSocket в дальнейшем необходимы reconnect/backoff, контроль свежести и REST fallback.

Текущая интеграция делает один общий REST-запрос NEPTUN каждые 30 секунд для всех групп, а не отдельный запрос на группу. Возможна задержка опроса и CDN. NEPTUN показывает треки угроз, а не официальный сигнал воздушной тревоги, поэтому тексты явно говорят об «активной угрозе», а не об объявлении официальной тревоги.

Сообщения NEPTUN содержат видимую ссылку на источник и пояснение, что агрегатор не заменяет официальные сигналы. Эти требования распространяются и на публичные сообщения об отбое.

## Проверка

Тесты `tests/test_neptun.py` покрывают обе миграции, сохранение источника и города, независимость групп, права администратора, переключение во время тревоги, недоступность источника, неверный ответ, Киев как отдельную территорию и атрибуцию. Существующие тесты Alerts.in.ua сохранены; тестовый объект БД дополнен методами чтения источника и города.
