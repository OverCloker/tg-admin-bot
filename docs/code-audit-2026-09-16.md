# Проверка кода — 16 сентября 2026

Проверены бот, API, Mini App и локальный media_publisher: регрессионные тесты,
статический анализ Python (Ruff F/E9), компиляция, согласованность зависимостей,
UTF-8/BOM и типичные повреждения кириллицы. Это локальная проверка исходников,
а не подтверждение состояния работающего Debian-сервера или его базы данных.

## Исправлено

- Права меню API рассчитываются один раз для всего ответа. Раньше полный набор
  прав повторно вычислялся для каждого элемента ADMIN_FEATURES.
- Фоновый YouTube-worker запускается и останавливается через FastAPI lifespan.
  Проверено завершение при исключении и отсутствие повторного запуска worker.
- Удалены неиспользуемый импорт и переменные, лишняя f-строка и перекрытие имени
  quote. Начисление награды экспедиции сохранено: удалена только ненужная переменная.
- Исправлено описание доступа к назначению ролей в помощи: оно соответствует
  существующей проверке администрации бота, а не обещает доступ владельцу группы.
- Ответ API карты читается частями с проверкой размера до накопления всего тела.
  Некорректная геометрия не сохраняется в суточный кэш.
- aiohttp и pydantic указаны как прямые зависимости: приложение импортирует их
  самостоятельно. Тяжёлые faster-whisper и yt-dlp используются действующими
  функциями, поэтому не удалены. PySide6 остаётся только в наборе desktop-приложения.
- В Docker-контекст не попадают backups, .ruff_cache и .pytest_tmp*.
- Проверка кодировок расширена на docs и templates.

## Проверка и ограничения

- Полный pytest, Ruff F/E9, compileall, pip check и разрешение requirements-test.txt
  в установленном окружении выполняются перед коммитом.
- Зависимости не обновлялись массово; Ruff установлен только как локальный
  инструмент аудита и не добавлен в серверные зависимости.
- Docker на этой Windows-машине отсутствует: сборка Linux-образа, время деплоя,
  реальные Telegram-запросы и данные производственной базы не проверялись.
- Автоматические проверки не доказывают отсутствие всех возможных ошибок.
