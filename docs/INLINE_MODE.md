# Погода и карта в переписке двух людей

В BotFather включите `/setinline` для бота и задайте подсказку, например
`погода и карта тревог`. Затем в любом обычном диалоге наберите:

- `@ypominanieBot погода Киев`
- `@ypominanieBot погода Киев завтра`
- `@ypominanieBot погода Киев неделя`
- `@ypominanieBot карта тревог`
- `@ypominanieBot карта тревог днепр`

Дождитесь результата и нажмите на него: прогноз или фотография карты
отправится собеседнику. Сам текст запроса отправлять не нужно.
Пустой запрос показывает примеры. История переписки боту не передаётся.

## Развёртывание

Обновите оба сервиса `bot` и `api`. Inline-запросы включены в список
событий polling. Новых библиотек не требуется.

Для фотографий задайте в `.env` публичный HTTPS-адрес API:

```dotenv
ADMIN_PUBLIC_URL=https://app.otvet04ka.com
```

Если он не задан, используется адрес из `MINI_APP_URL`.
Путь `/inline-media/<имя>.jpg` должен быть доступен Telegram без авторизации
и проверки Cloudflare на человека. Он выдаёт только подготовленные снимки,
не предоставляет доступ к другим файлам и не создаёт карты по HTTP-запросу.

`bot` сохраняет JPEG в `media_storage/inline_maps`, `api` отдаёт его Telegram.
В существующем Docker Compose эта папка уже находится в общем томе `bot_media`.
При отдельном запуске процессов они должны использовать общую папку проекта.
Старые снимки очищаются при создании новых (до 128 файлов, до суток).

Карта — снимок на время, указанное в подписи; уже отправленная фотография
не обновляется автоматически. Кеш карты составляет 30 секунд, inline-ответа —
20 секунд. Для новой карты повторите запрос и выберите результат.
