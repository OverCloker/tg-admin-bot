# Сверка оповещений Alerts.in.ua

Бот автоматически сохраняет успешные ответы API рядом с базой данных в
`alerts-diagnostics/responses.jsonl`. В Docker это `/data/alerts-diagnostics/`.
Каждая строка — JSON: время получения UTC, HTTP-статус, Last-Modified,
полный JSON ответа (payload), его SHA-256 и отдельно записи района 46 и области 9.
Токен API маскируется; заголовки авторизации не сохраняются.
304 означает отсутствие изменений: payload находится в предыдущей записи 200.
Снимок записывается до разбора данных. Дополнительных запросов к API нет.

При расхождении сохраните скриншот, точное время и часовой пояс, затем на Debian:

```sh
cd ~/tg-admin-bot
docker compose cp bot:/data/alerts-diagnostics ./alerts-diagnostics-export
```

Передайте файлы из этой папки для сверки. Делайте копию вскоре после события:
журнал циклический (активный файл 10 МБ и четыре резервных), старые записи удаляются.
Данные не доказывают наличие или отсутствие реальной угрозы: они позволяют
проверить, что именно сообщил API и как бот это отобразил.
Ответы до установки обновления восстановить этим журналом нельзя.
