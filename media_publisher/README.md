# Telegram Media Publisher

Локальное Windows-приложение для подготовки публикаций из папки с видео. Приложение работает только через исходящие запросы Bot API: `getMe`, `sendMessage`, `sendPhoto` и `sendMediaGroup`; polling, `getUpdates` и webhook не используются.

## Запуск MVP

```powershell
.\.venv\Scripts\python.exe -m pip install -r media_publisher_requirements.txt
.\.venv\Scripts\python.exe -m media_publisher.main
```

В окне выберите папку, укажите токен и Chat ID, затем нажмите «Сканировать». Настройки сохраняются в профиле Windows (`%APPDATA%/TelegramMediaPublisher/settings.json`), токен не попадает в репозиторий и не выводится в логи. Кнопки проверки подключения и тестовой отправки используют только введённые локально значения.

Для форум-группы выберите направление публикации и внесите его ID темы. Приложение отдельно запоминает ID для фильмов, мультфильмов, аниме, сериалов и остальных настроенных разделов. Пустой ID блокирует отправку теста, чтобы сообщение случайно не попало в основную тему. ID темы — средняя числовая часть ссылки вида `https://t.me/c/<chat>/<topic>/<message>`.

После сканирования выделите фильм, серию, сезон или весь сериал и нажмите «Опубликовать выбранное». Перед загрузкой приложение показывает Chat ID, направление и ID темы для подтверждения. Одиночные файлы отправляются отдельно, совместимые серии объединяются в медиагруппы до 10 файлов. Ограничения размера файлов определяются используемым Telegram Bot API.

Перед подтверждением приложение ищет карточку на Rezka, проверяя пользовательский домен и резервные зеркала. Антибот-заглушки и нерелевантные результаты отбрасываются. Если найдено несколько одноимённых произведений, они показываются в списке предпросмотра. Название, год, жанры, актёров, описание и URL постера можно исправить вручную. После подтверждения сначала публикуется постер с описанием, затем видео. Результаты поиска кэшируются в локальной SQLite-базе; при недоступности Rezka можно использовать настроенные ключи TMDB/OMDb.

MVP включает рекурсивное сканирование, разбор имён файлов (`S02E03`, «2 сезон 3 серия», качество, озвучка), группировку по сериалам/сезонам, предупреждения о пропусках и отправку медиагрупп до 10 файлов. Провайдеры TMDB/OMDb/Rezka и кэш публикаций подключены как расширяемые модули для следующих этапов.
