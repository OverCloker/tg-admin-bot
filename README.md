# Telegram Auto Reply Bot

Бот отвечает в группах, супергруппах и группах обсуждений, прикрепленных к каналам.
На текущем этапе прямые посты в канале бот не обрабатывает.

## Возможности

- автоответ на упоминание `@username`;
- фиксированные ответы на слова и фразы;
- выбор случайного участника дня из пользователей, которых бот уже видел в группе;
- настройка только администраторами конкретной группы;
- меню внутри Telegram через команды и inline-кнопки;
- SQLite-база без отдельного сервера.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Откройте `.env` и вставьте токен от BotFather.

Чтобы назначить администратора бота, узнайте свой Telegram id командой:

```text
/id
```

Затем добавьте id в `.env`:

```text
BOT_ADMIN_IDS=123456789
```

Можно указать несколько id через запятую. Администратор бота видит все группы, где есть бот.
Остальные пользователи видят только группы, где они являются администраторами.

## Запуск

```powershell
python -m app.bot
```

## Настройка в Telegram

1. Добавьте бота в группу или в привязанную к каналу группу обсуждений.
2. Выдайте боту права администратора.
3. В группе отправьте `/register_chat`.
4. Откройте личку с ботом, отправьте `/start` и выберите группу кнопкой.

## Команды

Настройки удобнее делать в личке с ботом через кнопки:

```text
/start
Выбрать группу
Добавить @ответ
Добавить слово
Списки ответов
Участники
Проверить доступ
Написать в чат
Настроить розыгрыш
Режим тревоги
```

В выбранной группе бот проверит, что вы администратор, и только после этого сохранит настройки.
Через кнопку `Написать в чат` можно отправить текст или стикер в выбранную группу от имени бота.
Если в группе включены темы, бот предложит выбрать тему. Чтобы тема появилась в списке,
в ней должно быть хотя бы одно сообщение после запуска бота или команда `/register_chat`.

Через кнопку `Режим тревоги` можно включить реакцию на слова `тревога` и `отбой` для выбранной группы.
Когда режим включен, слово `тревога` отключает медиа и реакции, а слово `отбой` возвращает права обратно.
Боту нужны права администратора на ограничение участников.

Старые команды внутри группы оставлены как запасной вариант:

```text
/setreply @username текст
/myreply текст
/delreply @username
/listreplies

/settrigger слово - текст ответа
/deltrigger слово
/listtriggers

/participants
/channels
/settings
```

Также распознаются русские команды:

```text
/старт
/настройки
/регистрация
/ответ @username текст
/мойответ текст
/удалитьответ @username
/списокответов
/тригер слово - текст
/триггер слово - текст
/удалитьтригер слово
/списоктригеров
/участники
/каналы
/помощь
```

Пример фиксированного ответа:

```text
/settrigger голубь - чмо
```

После этого, если кто-то напишет слово `голубь`, бот ответит заданным текстом.

## Участник дня

Фраза:

```text
кто пидор
```

Бот выберет случайного пользователя с `@username` из тех, кто уже писал в группе.
Выбор сохраняется на текущую дату, поэтому в течение дня результат будет одинаковым.

Чтобы база участников наполнилась, люди должны написать хотя бы одно сообщение после запуска бота.

## Погода

В группе можно написать:

```text
погода Кривой Рог
погода Кривой Рог завтра
погода Кривой Рог на завтра
погода Кривой Рог на неделю
погода Кривой Рог 7 дней
```

После слова `погода` можно указать любой город. Без периода бот покажет текущую погоду.

Через кнопку `Настроить розыгрыш` можно поменять фразу вызова, количество людей и заголовок.
Формат настройки:

```text
фраза вызова - количество - заголовок
```

Пример:

```text
кто пидор - 3 - Пидоры дня
```
