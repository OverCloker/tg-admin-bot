# Telegram Auto Reply Bot

Бот отвечает в группах, супергруппах и группах обсуждений, прикрепленных к каналам.
На текущем этапе прямые посты в канале бот не обрабатывает.

## Возможности

- автоответ на упоминание `@username`;
- фиксированные ответы на слова и фразы;
- выбор случайного участника дня из пользователей, которых бот уже видел в группе;
- настройка только администраторами конкретной группы;
- меню внутри Telegram через команды и inline-кнопки;
- SQLite-база без отдельного сервера.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Откройте `.env` и вставьте токен от BotFather.

Чтобы назначить администратора бота, узнайте свой Telegram id командой:

```text
/id
```

Затем добавьте id в `.env`:

```text
BOT_ADMIN_IDS=123456789
```

Можно указать несколько id через запятую. Администратор бота видит все группы, где есть бот.
Остальные пользователи видят только группы, где они являются администраторами.

## Запуск

```powershell
python -m app.bot
```

## Android admin API

Для Android-панели управления добавлен отдельный FastAPI-сервис:

```powershell
python -m uvicorn app.admin_api:app --host 0.0.0.0 --port 8000
```

В `.env` нужно добавить:

```text
ADMIN_API_KEY=длинный_секретный_ключ
ADMIN_ACTOR_ID=ваш_telegram_id_опционально
```

Android-приложение подключается к этому API и управляет теми же данными из `bot.sqlite3`: группами,
триггерами, @ответами, blacklist, цитатами, днями рождения, режимом тревоги, roll mute, quiet,
шахтой и Stars-платежами. Токен бота остается только на сервере в `.env`.

В браузере:

- `http://127.0.0.1:8000/` - веб-панель управления кнопками как в боте;
- `http://127.0.0.1:8000/docs` - техническая документация API.

В веб-панели кнопки админки можно настраивать удержанием примерно 1.5 секунды:
менять цвет, размер и порядок. Настройки сохраняются в браузере.

В меню веб-панели есть кнопки, соответствующие админ-панели бота, включая
`Проверить доступ` и `Перезагрузка`.

## Настройка в Telegram

1. Добавьте бота в группу или в привязанную к каналу группу обсуждений.
2. Выдайте боту права администратора.
3. В группе отправьте `/register_chat`.
4. Откройте личку с ботом, отправьте `/start` и выберите группу кнопкой.

## Команды

Настройки удобнее делать в личке с ботом через кнопки:

```text
/start
Выбрать группу
Добавить @ответ
Добавить слово
Списки ответов
Участники
Проверить доступ
Написать в чат
Настроить розыгрыш
Режим тревоги
```

В выбранной группе бот проверит, что вы администратор, и только после этого сохранит настройки.
Через кнопку `Написать в чат` можно отправить текст или стикер в выбранную группу от имени бота.
Если в группе включены темы, бот предложит выбрать тему. Чтобы тема появилась в списке,
в ней должно быть хотя бы одно сообщение после запуска бота или команда `/register_chat`.

Через кнопку `Режим тревоги` можно включить реакцию на слова `тревога` и `отбой` для выбранной группы.
Когда режим включен, слово `тревога` отключает медиа и реакции, а слово `отбой` возвращает права обратно.
Боту нужны права администратора на ограничение участников.

Старые команды внутри группы оставлены как запасной вариант:

```text
/setreply @username текст
/myreply текст
/delreply @username
/listreplies

/settrigger слово - текст ответа
/deltrigger слово
/listtriggers

/participants
/channels
/settings
```

Также распознаются русские команды:

```text
/старт
/настройки
/регистрация
/ответ @username текст
/мойответ текст
/удалитьответ @username
/списокответов
/тригер слово - текст
/триггер слово - текст
/удалитьтригер слово
/списоктригеров
/участники
/каналы
/помощь
```

Пример фиксированного ответа:

```text
/settrigger голубь - чмо
```

После этого, если кто-то напишет слово `голубь`, бот ответит заданным текстом.

## Участник дня

Фраза:

```text
кто пидор
```

Бот выберет случайного пользователя с `@username` из тех, кто уже писал в группе.
Выбор сохраняется на текущую дату, поэтому в течение дня результат будет одинаковым.

Чтобы база участников наполнилась, люди должны написать хотя бы одно сообщение после запуска бота.

## Погода

В группе можно написать:

```text
погода Кривой Рог
погода Кривой Рог завтра
погода Кривой Рог на завтра
погода Кривой Рог на неделю
погода Кривой Рог 7 дней
```

После слова `погода` можно указать любой город. Без периода бот покажет текущую погоду.

Через кнопку `Настроить розыгрыш` можно поменять фразу вызова, количество людей и заголовок.
Формат настройки:

```text
фраза вызова - количество - заголовок
```

Пример:

```text
кто пидор - 3 - Пидоры дня
```

## Staff System

Staff System предназначена для внутреннего управления разработкой и администрированием бота через закрытую Telegram-супергруппу с включёнными темами.

1. Создайте закрытую супергруппу и включите Topics.
2. Создайте темы: `Общее`, `Статус`, `Логи`, `Баги`, `Задачи`, `Идеи`, `Релизы`.
3. Укажите Telegram ID владельца в `OWNER_ID` файла `.env`.
4. Добавьте бота администратором и выполните `/bind_staff` внутри staff-группы.

Telegram Bot API не позволяет получить полный список уже существующих тем по запросу. Бот находит названия среди ранее сохранённых тем и автоматически запоминает темы, когда видит их создание или переименование. Отсутствующие темы записываются как предупреждения в логи.

Если существующая тема не определилась автоматически, выполните внутри неё `/bind_staff ключ`, например `/bind_staff logs`. Доступные ключи: `general`, `status`, `logs`, `bugs`, `tasks`, `ideas`, `releases`. Пока тема не привязана, предназначенное ей сообщение сохраняется в таблице логов и не перенаправляется в «Общее».

Назначение тем:

- `Общее` — заметки и уведомления об изменениях автоответов.
- `Статус` — запуск, остановка и технический статус бота.
- `Логи` — последние записи и критические ошибки.
- `Баги` — карточки найденных ошибок.
- `Задачи` — открытые и закрытые задачи.
- `Идеи` — предложения команды.
- `Релизы` — сообщения о новых релизах.

Staff-команды доступны только владельцу бота и администраторам привязанной staff-группы:

```text
/bind_staff
/status
/logs
/bug описание
/task описание
/tasks
/done ID
/idea текст
/release текст
/note текст
```

## Premium

Медиа-функции приложения и Premium-бонусы шахты доступны только при активной подписке. Бесплатного тарифа нет. Тарифы централизованно описаны в `app/premium.py`.

| Тариф | Цена | Задач в день | Файл | Расшифровка | Очередь | Шахта |
|---|---:|---:|---:|---:|---|---|
| Базовый премиум | 50 Stars / 30 дней | 3 | до 50 МБ | до 5 минут | обычная | −15% ожидания, +15% монет, +15% восстановления удачи |
| Расширенный премиум | 100 Stars / 30 дней | 30 | до 200 МБ | до 30 минут | ускоренная | −35% ожидания, +35% монет, +35% восстановления удачи |

Команды Telegram:

```text
/premium
/buy_basic
/buy_extended
```

Пользовательское Android-приложение MonkeyDin показывает текущий Premium, использование дневного лимита и кнопки покупки обоих тарифов. Владелец бота дополнительно видит кнопку тестового Расширенного Premium на 24 часа. Админское Android-приложение Abstergo показывает owner-only раздел `Premium` со списком покупателей, тарифами и датами окончания.

Premium-платежи используют Telegram Stars (`XTR`). После успешной оплаты подписка сохраняется в таблице `subscriptions`, а покупка также попадает в существующий журнал Stars.

### Premium API

API работает в существующем FastAPI-модуле `app.admin_api`. Временная авторизация приложения передаёт Telegram ID пользователя в заголовке:

```text
X-Telegram-User-Id: 123456789
```

Это временная заглушка. Перед публичным запуском её необходимо заменить проверкой Telegram initData/Auth.

Endpoints:

```text
GET  /premium/plans
GET  /premium/me
POST /media/tasks
GET  /media/tasks
GET  /media/tasks/{id}
```

Авторизованные endpoints пользовательского приложения:

```text
GET  /user/premium/plans
GET  /user/premium/me
POST /user/premium/invoice/{basic|extended}
POST /user/premium/test
```

`/user/premium/test` доступен только `OWNER_ID` и выдаёт тестовый Расширенный Premium на 24 часа. Админский список подписок доступен владельцу через `GET /admin/premium/subscriptions`.

Пример создания задачи:

```json
{
  "taskType": "transcription",
  "sourceFileId": "telegram-file-id",
  "fileSizeBytes": 1048576,
  "durationSeconds": 120
}
```

Поддерживаемые `taskType`:

```text
video_convert
audio_convert
extract_audio
compress_video
compress_audio
trim_audio
trim_video
transcription
gif_create
```

Задачи сохраняются со статусом `queued`. Следующая задача выбирается через `get_next_media_task()`: сначала меньший `priority`, затем более ранний `created_at`. Локальные медиафайлы обрабатываются FFmpeg, а расшифровка выполняется Faster-Whisper.

## YouTube и YouTube Music

Бот поддерживает публичные ссылки без авторизации и обхода ограничений:

- `youtube.com/watch`
- `youtu.be`
- `youtube.com/shorts`
- `music.youtube.com/watch`

После отправки ссылки в личный чат бот сначала показывает выбор формата и ничего не скачивает автоматически. Для YouTube доступны MP4 до 720p и MP3 192 kbps. Для YouTube Music доступны MP3 192 kbps и лучший доступный M4A-поток без перекодирования, когда это возможно.

Скачивание использует существующие Premium-проверки, дневные лимиты, `media_tasks`, приоритет очереди и журнал логов. Итоговый размер повторно проверяется после работы `yt-dlp`. Приватные, удалённые, регионально недоступные и защищённые материалы не скачиваются.

API:

```text
POST /youtube/download
X-Telegram-User-Id: 123456

{
  "user_id": 123456,
  "url": "https://youtu.be/...",
  "download_type": "video_mp4"
}
```

Допустимые `download_type`: `video_mp4`, `audio_mp3`, `music_mp3`, `music_m4a`. Статус созданной задачи доступен через `GET /media/tasks/{id}`.

Задачи, созданные через API, автоматически забираются YouTube-worker из общей очереди. Несколько запущенных API-процессов безопасно конкурируют за задачи: каждая задача атомарно переводится в `processing` только одним worker.

Временные файлы находятся в `downloads/temp/`, результаты обработки — в `downloads/youtube/`. После успешной отправки бот удаляет итоговый локальный файл.

Проверка:

```powershell
python -m py_compile app\bot.py app\admin_api.py app\youtube_media.py
python -m app.bot
uvicorn app.admin_api:app --host 0.0.0.0 --port 8000
```

## Распознавание радио

Для распознавания треков из MonkeyDin добавьте в `.env`:

```env
AUDD_API_TOKEN=your_audd_api_token
```

MonkeyDin сначала пытается прочитать `StreamTitle`. Если метаданных нет, сервер записывает 15 секунд эфира через FFmpeg и отправляет фрагмент в AudD. Базовый Premium включает 10 распознаваний в день и запись эфира до 10 минут. Расширенный Premium включает 100 распознаваний, историю треков и запись до 60 минут.

## Пользовательское приложение

Пользовательское приложение использует отдельную авторизацию через Telegram-бота и не принимает админские ключи.

1. `POST /user/auth/start` возвращает одноразовую ссылку на бота, `loginId` и секрет для опроса.
2. Пользователь открывает ссылку и подтверждает вход командой `/start app_<loginId>`.
3. Приложение вызывает `POST /user/auth/status` и получает долгоживущий токен с префиксом `usr_`.
4. `GET /user/me` возвращает профиль и состояние подписки.
5. `POST /user/subscription/invoice` создаёт ежемесячную подписку Telegram Stars.

Стоимость подписки задаётся через `USER_SUBSCRIPTION_STARS`, по умолчанию `100`.
## Debian Docker

Для переезда на Debian через Docker подготовлены:

- `Dockerfile`
- `docker-compose.yml`
- `DOCKER_DEBIAN.md`

Схема запуска: отдельный сервис `bot` для Telegram polling и отдельный сервис `api` для FastAPI. Оба сервиса используют общие Docker volumes для SQLite, медиа, загрузок и логов. API публикуется наружу на `8000` и `50000`, оба порта ведут в один FastAPI-процесс.

Перед переносом остановите Windows-запуск, скопируйте `bot.sqlite3`, `.env`, `admin_access_keys.json`, `downloads/`, `media_storage/`, `logs/` и следуйте инструкции в `DOCKER_DEBIAN.md`.
# Безопасность развёртывания

- Публикуйте API для Android-приложений только через HTTPS. Открытый `http://PUBLIC_IP:8000` передаёт пользовательские и административные bearer-сессии без шифрования.
- Порты `8000` и `50000` не должны быть одновременно открыты в интернет. Оставьте один внутренний порт и поставьте перед ним reverse proxy с TLS (Caddy, nginx или Tailscale HTTPS).
- После утечки или копирования `.env` замените токен бота через BotFather, `ADMIN_API_KEY`, ключ Alerts.in.ua, AudD и секрет Spotify.
- Переносимый пакет намеренно не включает `.env`, `bot.sqlite3` и `admin_access_keys.json`. Создавайте `.env` из `.env.example`, а резервную копию БД передавайте отдельно по доверенному каналу.
- Контейнеры запускают приложение от непривилегированного пользователя. При первом запуске entrypoint один раз исправляет владельца существующих Docker volumes.
