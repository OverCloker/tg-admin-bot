# Widget icons

- Bulb and bulb-off: Tabler Icons, MIT, https://github.com/tabler/tabler-icons .
  Paths imported from the official outline SVGs into Android VectorDrawable,
  preserving source geometry; only stroke width and semantic color adapted.
- Energy, refresh and chevron: Google Material Design Icons, Apache-2.0,
  https://github.com/google/material-design-icons .
  Official outline path geometry retained, converted to Android VectorDrawable.
- Surface shapes and time-series timeline are native UI containers/data visualization,
  not replacements for illustrated assets.
